# AI-Scrum-Master-Workflow
AI-assisted Agile delivery workflow for Scrum Masters and PMs

## Overview
This project demonstrates how AI tools can improve Agile delivery management, sprint visibility, stakeholder communication, and reporting automation.

---

## Tools Used
- Claude
- Notion AI
- Zapier
- Perplexity
- Canva AI
- Beautiful.ai

---

## Features
- AI-generated sprint summaries
- Stakeholder communication
- Retrospective analysis
- Sprint reporting
- Agile workflow automation

---

## Project Structure

### sprint-data
Sprint updates and summaries

### stakeholder-updates
AI-generated stakeholder communication

### retrospectives
Retrospective insights and action plans

### automation-workflows
Zapier automation examples

### dashboards
Sprint visuals and reporting examples

### prompts
Reusable AI prompts for Scrum workflows

---

## Objective
To explore how AI tools can improve Scrum Master and Project Management workflows.
